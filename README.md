# 岡山市オープンデータ GIS学習

## 1. データ
岡山市の公園データメモ

| 項目 | 内容 |
| **データ名称** | 岡山市 公園一覧 |
| **取得元** | 岡山市オープンデータポータル |
| **対象エリア** | 岡山市北区周辺（約2〜4km四方） |
| **主要カラム** | 名称, 住所, 経度, 緯度, 多機能トイレ有無 |
| **文字コード** | UTF-8 |
| **座標参照系(CRS)** | WGS 84 (EPSG:4326) |
| **ライセンス** | CC BY 4.0 |

---

## 2. GeoJSONデータ

Feature：１つの箱　この中にデータがいろいろ入ってる
└──properties(プロパティ)：属性、中身のデータを書くための仕切り　名札みたいなもん
　├─Point：点　１つの場所を指すときつかう「ここがねこねこ公園」
　├─Polygon：面　エリアを囲むとき使う「ここからここまでの敷地がねこねこ公園」

エリアの場合は
[
    外枠
    [ [経度,緯度], [経度,緯度], [経度,緯度], [経度,緯度],],
    くりぬく部分(あれば)
    [[経度,緯度] [経度,緯度], [経度,緯度], [経度,緯度],]
]
くりぬく部分なければ外枠の部分にだけ書いたらOK


```json
{
  "type": "FeatureCollection",//固定
  "features": [　　　　　　　//データの配列の集まりs
    {
      "type": "Feature",　　//データの中身の配列①
      "properties": {
        "category": "公園",
        "name": "ねこねこ公園"
      },
      "geometry": {
        "type": "Point",
        "coordinates": [133.918, 34.662]
      }
    },
    {
      "type": "Feature",　　//データの中身の配列②
      "properties": {
        "category": "公園",
        "name": "いぬいぬ公園"
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
         [        //面　公園全体の集合
          [       //線　輪郭
           [133.9180, 34.6620],  // 点1（スタート）経度,緯度
           [133.9190, 34.6620],  // 点2
           [133.9190, 34.6610],  // 点3
           [133.9180, 34.6610],  // 点4
           [133.9180, 34.6620]   // 点5（スタートと同じ座標で閉じる）
          ]
         ]
        ]
      }
    }
  ]
}
```
